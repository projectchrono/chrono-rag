# chrono-rag
A RAG application which will be an oracle for users in Chrono Forums.

# Steps to build this
1. We need the data from [Chrono repository](https://github.com/projectchrono/chrono) and [PyChrono Examples](https://github.com/projectchrono/pychrono-examples-9.0)

2. Lets try to focus on building a RAG that will solve one very simple task. That will create a skeleton on which we can make it better.

3. Therefore, lets for the time being, start with a small data.
